Setup and security instructions

Host this HTML page on an HTTPS static website (e.g. GitHub Pages or Azure Static Web Apps). In Microsoft Entra admin center, register an app → Authentication → Single-page application → add the exact page URL as redirect URI. Allow personal Microsoft accounts if using personal OneDrive. Under API permissions add delegated Microsoft Graph Files.ReadWrite and User.Read. If your organization requires administrator consent, ask its admin. This app requests delegated access; it does not use a client secret. Upload the original XLSX to your OneDrive root or change the path above. This page needs internet and an authorized Microsoft account. Do not publish a preconfigured client ID with private workbook information on a public site.
